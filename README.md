# MC 地图册

Minecraft 种子地图与服务器查询工具。纯静态站点，无需构建。

在线地址：https://mc-atlas.app.workbuddy.host/

## 功能

**种子地图** — 输入种子即可查看真实地形，支持 1.8.9 至 1.21.8 共 14 个版本与主世界 / 下界 / 末地三个维度。地形与建筑由 [cubiomes](https://github.com/Cubitect/cubiomes) 计算，与游戏内生成一致：选 1.20 时不会出现试炼密室，选 1.8 时不会出现古迹废墟，这些差异来自引擎对版本的真实判定，不是写死的开关。

**搜索** — 统一搜索地形与建筑，点击结果跳到最近的一处，可循环查看下一个。附带出生点、史莱姆区块、区块网格等标记。

**服务器查询** — 输入地址查看 MOTD、版本、延迟、在线人数与在线玩家名单。同时问三路公共接口，任一有明确答复即采用；三路都请求失败时会明确提示"没能问到"，不会把"查不到"误判成"服务器不存在"。

**云同步** — 登录后收藏与查询历史保存在云端，换设备不丢。

## 本地运行

必须通过 HTTP 打开，直接双击 `index.html`（`file://`）会导致浏览器拒绝加载 WASM，地形会退化为近似引擎。

```bash
python -m http.server 8000
# 然后访问 http://127.0.0.1:8000/
```

云服务登录只在发布的域名上生效，本地打开时登录会失败，其余功能不受影响。

## 结构

```
assets/js/
  core/    引擎封装与版本、群系数据（含 WASM 不可用时的 JS 近似兜底）
  map/     地图渲染、瓦片 Worker 池、最近地形与建筑搜索
  net/     服务器状态与正版账号查询，数据源按描述对象注册，新增只需追加
  cloud/   云服务接入（认证、读写）
  ui/      各面板
assets/vendor/seedmaps-engine-wasm/  cubiomes 编译产物
```

地形渲染放在 Web Worker 池里并行：cubiomes 是单线程 C 代码，单帧满屏采样在桌面约需 2 秒，分条带并行后降到 0.5 秒左右。

## 关于数据来源

服务器状态与正版账号均查询第三方公开接口。浏览器无法直连 25565 端口，也无法读取不带 CORS 响应头的接口（Mojang 官方接口即属此类），因此只使用实测带 `Access-Control-Allow-Origin` 的数据源。

**服务器不对外暴露玩家坐标**，任何纯前端工具都拿不到真实位置。界面中的坐标在未接入服务端接口时为演示值，并已明确标注；填入自己的插件接口即可显示真实坐标。
